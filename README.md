CRIME RECORD MANAGEMENT SYSTEM

The Crime Record Management System (CRMS) is a software application designed to assist law enforcement agencies in managing and tracking criminal records and related data efficiently. The system serves as a centralized platform where various details of criminal cases, suspects, victims, and related legal information are stored, retrieved, and updated. This project includes features such as:

Crime Case Management: Enables law enforcement officers to log and manage criminal cases, including descriptions, evidence, witness details, and investigation progress.

Suspect and Victim Database: Maintains a record of suspects and victims with personal details, criminal history, and links to ongoing or past cases.

Crime Case Status Tracking: A feature allowing users to monitor the current status of cases, such as 'open', 'under investigation', 'closed', etc.

Search and Reporting: Facilitates searching for specific cases, individuals, or crime types. It also generates reports on crime statistics based on various parameters like location, crime type, etc.

User Access Control: Implements role-based access, ensuring that only authorized personnel (officers, admins, etc.) have access to sensitive information.

Integration with Firebase: The system uses Firebase for secure authentication, database storage, and real-time data synchronization across multiple devices.
