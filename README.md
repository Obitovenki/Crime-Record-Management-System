# Crime Record Management System (CRMS) Dashboard

## Overview

The **Crime Record Management System (CRMS)** is a web-based application designed to manage and track crime records efficiently. This repository contains the code for the dashboard interface of CRMS.

## Features

- **Dashboard Interface**: Provides a welcoming and informative dashboard for users.
- **Navigation Menu**: Links to various sections of the CRMS, including Staff Management, Crime Case Status, New Crime Updates, Crime Case Booking, and Criminal Records.
- **Responsive Design**: Styled with a modern theme and responsive design for better user experience.
- **Interactive Elements**: Includes modals for error messages and interactive navigation links.
